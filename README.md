# 互动课件大师（Interactive Courseware Master）

> 一句话：**你说出想讲的知识点，AI 帮你做出一个能上课直接用的互动动画课件。**

这是一个面向 **Cursor / Claude Code / Codex / OpenClaw 等 AI 助手**的 Agent Skill（技能包）。安装后，你只需要用平常说话的方式告诉 AI："帮我做一个讲月相变化的课件"，它就会生成一个**双击就能打开的网页文件**——里面有 3D 动画、可拖动的滑块、学习目标和小测验，连上投影仪就能上课。

**为不懂代码的教师设计：全程不需要写一行代码，不需要安装任何软件。**

## 你会得到什么

对 AI 说一句话，比如：

> "我是高中地理老师，帮我做一个讲月相变化'上上西西下下东东'的课件"

AI 会生成一个 `moon-phases.html` 文件，**双击打开**就是一个完整课件：

- 🌙 **3D 动画演示**：太阳-地球-月球的立体场景，鼠标可以拖动旋转
- 🎚️ **互动滑块**：拖动"农历日期"滑块，月相实时变化
- 📚 **左侧知识栏**：学习目标、核心公式、通俗原理解释
- 📝 **内置小测验**：3 道选择题，点击按钮展开，不遮挡动画
- ⛶ **一键全屏**：投影上课专用

**所有面板都可以折叠收起，永远不会挡住正在播放的动画。**

## 快速开始（3 步）

1. **安装技能**（见下方[安装](#安装)，只需复制粘贴一条命令）
2. **对 AI 说出你的需求**：

   ```
   帮我做一个讲 [知识点] 的课件，学生是 [初二/高一/...]
   ```

3. **双击生成的 HTML 文件**，开始上课 🎉

## 课堂使用指南

生成的课件页面布局：

```
┌──────────────────────────────────────────────┐
│ 标题栏： 🔄重置  🎲随机演示  ⛶全屏              │
├───────────────┬──────────────────────────────┤
│ 知识栏         │        3D 动画区              │
│ ·学习目标      │   （鼠标拖动旋转视角）          │
│ ·核心公式      │                              │
│ ·原理解释      │  [📝小测验]  ← 点击才展开      │
│               │  [▶播放 ⏸暂停 滑块…] ← 可收起  │
└───────────────┴──────────────────────────────┘
```

上课建议：

1. 开场点 **⛶ 全屏**，让动画铺满投影幕布
2. 讲解时拖动**滑块**，让学生观察参数变化带来的即时效果
3. 讲完知识点，点 **📝 小测验** 现场提问
4. 点 **🎲 随机演示** 让学生判断当前状态，活跃气氛

## 常见问题

**Q：我完全不懂代码，能用吗？**
A：能。你只和 AI 对话，它负责生成文件。生成的课件双击就能打开，和打开一个 PPT 一样简单。

**Q：上课的教室没有网络怎么办？**
A：课件首次打开需要联网加载动画库；建议提前在有网络的地方打开一次。知识栏内容离线也能显示。

**Q：生成的课件内容有错怎么办？**
A：直接告诉 AI"第二个公式写错了，应该是……"，它会重新生成修正后的文件。

**Q：能改颜色、改标题吗？**
A：能。对 AI 说"把主色改成绿色"、"标题改成《XX中学地理课》"即可。

## 这个技能是怎么工作的

| 文件 | 作用 | 给谁看 |
|------|------|--------|
| `README.md` / `README.en.md` | 介绍和使用说明 | 给**人**看 |
| `SKILL.md` | 技能规范：页面结构、交互规则、视觉标准 | 给 **AI** 看 |
| `examples/` | 参考成品课件 | 人和 AI 都看 |

当你对 AI 提出课件需求时，AI 会读取 `SKILL.md` 中的规范（如"浮动面板绝不遮挡展示区"、"界面按钮必须中文+emoji"），按统一标准生成课件，保证每次产出的质量稳定。
